新主機系統映像檔備份紀錄

Windows 11 家用版 · 備份與還原(Windows 7)工具 · 第三階段（乾淨版備份）

備份工具：Windows 內建「備份與還原（Windows 7）」
備份位置：WD Elements 2TB 外接硬碟（代號 E:）
備份內容：EFI 系統磁碟分割 + C 槽（系統）+ Windows 修復環境
備份時機：硬碟分割完成後、尚未安裝任何軟體的「乾淨起點」狀態
結果：✅ 備份成功完成，佔用約 60GB 空間

1 為什麼要在「裝軟體之前」先做一份？

這份映像檔是整個備份計畫的「乾淨基礎版本」，用途和之後要做的「完整版」不同。

兩種映像檔的差別

時間點用途
分割完、軟體都還沒裝（本次）「回到出廠設定」的救命符，系統中毒或變得一團亂時，可以打回這個乾淨起點
軟體都裝好之後（下一階段）「完整可用狀態」的救命符，還原後直接能用，不用重新裝一次軟體
兩份都會保留在外接硬碟上，互不取代；日後有需要優先使用較新、內容較完整的那份。

2 開啟備份工具

Step 2-1　控制台 → 系統及安全性

路徑：控制台 →「系統及安全性」→「備份與還原（Windows 7）」。雖然名稱掛著 Windows 7，但在 Windows 11 上功能完全正常。

Step 2-2　備份與還原主畫面

左側選單有兩個關鍵功能：建立系統映像（本次要做的）與建立系統修復光碟（後續改用更完整的安裝隨身碟取代）。

3 建立系統映像

Step 3-1　選擇儲存位置

選「硬碟上」，系統自動偵測到 Elements (E:) 1.82 TB 可用，也就是 WD 外接硬碟，直接使用即可，不需更改。

Step 3-2　確認要備份的磁碟機

系統自動勾選必要項目：EFI 系統磁碟分割、(C:) 系統、Windows 修復環境；新增磁碟區 (D:) 刻意不勾選，因為 D 槽是雲端同步資料夾，雲端本身已有備份，不需重複收錄進映像檔。

所需空間：59.80 GB／外接硬碟可用空間：1.82 TB，空間十分充裕。

Step 3-3　確認備份設定

最終確認畫面：備份位置 Elements (E:)，最多需要 60GB 空間，備份項目為 EFI 系統磁碟分割、C 槽（系統）、Windows 修復環境。確認無誤後點擊「開始備份」。

Step 3-4　備份進行中 → 詢問是否建立系統修復光碟

備份跑完後，系統會跳出視窗詢問「要不要建立系統修復光碟？」。因為後續改用微軟官方 Media Creation Tool 製作功能更完整的安裝隨身碟（同時具備修復＋全新安裝兩種功能），此處選擇「否」，不影響已完成的映像檔備份。

Step 3-5　備份成功完成

畫面顯示「備份成功完成」，第一份乾淨版系統映像檔正式存入 WD 外接硬碟。

確認結果：乾淨版系統映像檔備份完成，約佔用 60GB 空間，存於 WD Elements 2TB 外接硬碟。

4 之後如何使用這份映像檔（急救參考）

平常完全用不到，只有系統嚴重故障、需要還原時才會用上，先記錄操作方式備查。

還原時機與方式

狀況等級處理方式
系統變慢、當機、疑似中毒（仍可開機）先重開機、掃毒、解除安裝可疑軟體，不需要動用映像檔
系統開不了機、損毀嚴重用安裝隨身碟開機 →「修復您的電腦」→「疑難排解」→「進階選項」→「系統映像修復」，選擇外接硬碟裡的映像檔還原
硬碟物理損壞、映像檔也救不回來用安裝隨身碟「立即安裝」，全新安裝 Windows，安裝後登入 chariotgina@gmail.com 自動取回數位授權
還原後電腦會恢復成「做映像檔當下」的狀態，因此軟體都裝好後記得補做一份「完整版」映像檔，取代/補充這份乾淨版，未來還原才不用重新安裝軟體。
